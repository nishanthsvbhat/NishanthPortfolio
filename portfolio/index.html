Fake News Detection
using Data & AI

End-to-end fake news verification system fusing a 5-model ML ensemble with Groq Llama 3.3 70B LLM. Features a 5-agent Agentic RAG pipeline built with LangChain and FAISS, NLP explainability via LIME/SHAP, and a Streamlit + FastAPI production deployment.

Agent Pipeline
The Problem
Misinformation spreads 6x faster than verified news. Existing single-model detectors produce high false positive rates and can't explain their decisions to end users.
The Approach
Fused five ML classifiers (LR, SVM, RF, XGBoost, NB) into a weighted ensemble, then layered Groq Llama 3.3 70B for contextual verification through a 5-agent RAG pipeline with FAISS retrieval.
