# Nishanth S V — Personal Portfolio

A modern, dark-themed personal portfolio built with **HTML, CSS, and Vanilla JavaScript**. Designed to showcase AI/ML, Data Science, and Full Stack Development work.

## ✨ Features

- **Glassmorphism Navbar** with scroll-triggered backdrop blur
- **Animated Hero** with stat counters, floating code card, and tech badges
- **Scroll Reveal** animations using IntersectionObserver
- **Vertical Timeline** for experience with animated glow line
- **Skill Badges** with hover glow effects and Devicons
- **Featured Project Card** with impact stats
- **Certifications Grid** with hover interactions
- **Contact Section** with styled form and info cards
- **Mobile-First Responsive** design (320px → 1440px+)
- **Reduced Motion** support for accessibility

## 🛠 Tech Stack

- HTML5, CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript (IntersectionObserver, requestAnimationFrame)
- Google Fonts: Space Grotesk, Inter, JetBrains Mono
- Devicons CDN for tech skill icons
- No frameworks. No build step.
